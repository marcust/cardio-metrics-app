Cardio Metrics

Cardio Metrics is a personal Google Apps Script project run by Marcus More-Thiesen for his own use. It is not offered to other users.

Once an hour it reads the owner's own fitness data from the Google Health API (cardio fitness / VO2max, resting heart rate and minute heart rate) and writes it into a private Google Sheet that only the owner can access. The sheet is used to follow long-term training and health trends.

The app only reads data, never changes it, and shares nothing with anyone else.
